IN-GAME NETPLAY FOR EFZ
======================

This mod adds a NETPLAY menu inside Eternal Fighter Zero.

Install
-------
1. Close the game.
2. Install EFZ Mod Manager if you do not already have it.
3. Copy the mod folder into your EFZ folder:

   <EFZ folder>\mods\efz_netplay_mod\

4. The folder should contain:

   efz_netplay_mod.dll
   assets\

5. Make sure these Revival files are beside efz.exe:

   EfzRevival.dll
   EfzRevival.exe
   EfzRevival.ini

6. Open EfzModManager.ini beside efz.exe and add:

   efz_netplay_mod=1

7. Launch the game with efz.exe.

Do not launch through EfzRevival.exe or Concerto.exe while this mod is enabled.

Quick Start
-----------
Open NETPLAY from the title screen.

Host:
  Choose Host, start hosting, then share the shown address and port.

Join:
  Choose Join, enter the host address and port, then connect.

Player Rooms / Lobby:
  Use these to find other players, create rooms, challenge players, or spectate.

Options:
  Change nickname, port, keybinds, logging, and other netplay settings.

Battle Log:
  View recorded sets and match history.

Notes
-----
- Keep efz_netplay_mod.dll and the assets folder together.
- Make sure both players use compatible EFZ Revival and mod versions.
- If players cannot connect, the host may need port forwarding.
- The mod writes efz_netplay_mod.log near the DLL when file logging is enabled.
